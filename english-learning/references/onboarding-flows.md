# Onboarding and placement flows

Use this reference only for a new learner, a requested restart, or a requested reassessment. Ask one question at a time. Every question must have numbered choices and a final free-response choice. Never dump the questionnaire as one form. Begin directly with the full-path interest stage.

## Universal question pattern

All answer options must use Arabic numerals (`1.`, `2.`, `3.`). Never use letters (`A/B/C` or `a/b/c`) to mark answers, including in English vocabulary, grammar, sentence-selection, and placement questions.

Prefer the host's native clickable answer controls. Each click should submit the selected choice and lead to the next dependent question. Only the final comments/own-answer choice opens or requests typed input. If the host has no native choice control, show the numbered fallback and accept the number.

Before presenting any scored item, shuffle the substantive answer choices. Vary the correct answer's number across the sequence and prevent `1` from becoming the default. Keep the comments/own-answer option last. Evaluate the selected answer by its text/meaning, never by assuming a fixed number is correct.

Use this shape:

```text
שאלה קצרה שמזכירה פרט רלוונטי מהתשובה הקודמת:

1. אפשרות ברורה אחת
2. אפשרות ברורה אחרת
3. אפשרות שלישית, אם היא באמת שימושית
4. אחר / הערות — אפשר לכתוב חופשי
```

Do not use `אחר` without explicitly allowing comments. When a task needs original English, make the final option `My own answer / comments — write freely`.

## Full path: adaptive branches

Ask 8–14 onboarding questions. Begin with outcomes 1–3 below so interests visibly come first; cover the rest adaptively rather than as a rigid questionnaire:

1. first broad interest lane
2. concrete example inside that lane
3. second distinct interest or useful context
4. specific example inside the second lane when needed
5. age group
6. practical goal and the real-life situations where English should help
7. requested learning focus: speaking, listening, vocabulary, grammar, reading, writing, pronunciation, or everything
8. current confidence or difficulty
9. rejected or unwanted topics
10. adult work context only when selected or clearly relevant
11. upcoming trip, test, interview, presentation, or event only when relevant

Ask practical goal and learning focus as two separate questions. In the focus question, always include `הכול — אני רוצה לחזק את כל תחומי האנגלית` as a substantive option before the final comments option. If selected, build a balanced plan and use placement evidence only to choose which skill receives extra attention first.

Use remaining questions only to resolve meaningful ambiguity. If the learner chooses music, ask genre or artist next; do not jump to gaming. If they choose work, ask what English situation occurs there; do not ask for employer name. If they choose travel, ask destination or travel situation, then use it in placement examples.

Summarize and confirm with:

1. הכול מדויק — אפשר לעבור לבדיקת הרמה
2. אני רוצה לשנות את המטרה
3. אני רוצה לשנות את תחומי העניין
4. אחר / הערות — אפשר לכתוב חופשי

## Full placement: adaptive multiple choice

Use 8–15 items, maximum 18. Start near the learner's self-reported level and adapt one band at a time.

If the learner reports no knowledge or misses the earliest word and sentence checks, branch to a short Pre-A1 foundation check: recognizing a few uppercase/lowercase letters, matching a common letter to its sound, and recognizing one very common spoken or written word. Keep `אני עדיין לא יודע/ת` or comments last. Use the result to decide whether lesson 1 should begin with alphabet/sound foundations or usable words and phrases. Do not assign alphabet work merely because the overall level is Pre-A1.

Sample these dimensions without asking all at once:

- vocabulary meaning in a personal context
- basic sentence comprehension
- present/past/future use
- question formation
- short reading inference
- error recognition
- sentence completion
- original production

For each answer:

- explain only what is useful
- use the error type to select the next item
- make the next item slightly easier after two consecutive failures
- make it slightly harder after two clear successes
- revisit an uncertain pattern through a new personal context

Recognition alone supports only a provisional estimate. Before B1+, require at least two original answers through `My own answer / comments` and evaluate meaning, grammar, and independence.

After the last item, explain the estimated level, strengths, main gap, and first recommended target. Then ask lessons per week, minutes per lesson, and readiness to begin lesson 1 as three separate clickable multiple-choice questions ending in comments. These are planning questions, not placement items.

## Lesson questions

Keep the multiple-choice rule without turning lessons into constant quizzes:

- comprehension: 2–4 choices plus comments
- guided production: 2–3 sentence starters plus own answer/comments
- conversation: 2–3 possible directions plus own answer/comments
- reflection: continue, review, change difficulty, or comments

Count a selected answer as recognition evidence. Count only a genuinely original response as independent productive evidence.

Shuffle correct-answer positions in lesson checks just as in placement. After every 3–5 completed lessons, use one clickable comparison grounded in recent activities to learn which format helped or engaged the learner more; do not ask this during initial onboarding.
