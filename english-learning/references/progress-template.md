## Counting rules

- Count a meaningful exposure only when the learner attends to meaning or use.
- Count an independent use only when the learner retrieves and uses the item correctly without a revealing hint.
- Count a supported use when a hint, model, choice, translation, or correction enabled the response.
- Record a failed recall when the learner cannot retrieve the item or substitutes it incorrectly after a fair prompt.
- Add no more precision than the session evidence supports.
- A stopped-early session may update learning evidence and review timing, but it must not increase `Total completed sessions`.
